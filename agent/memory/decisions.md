# Decisions

## Navigation
Using floating navigation trigger with cinematic side drawer.

Reason:
Preserve immersion and avoid traditional navbar clutter.

## Design Tone
Luxury hospitality aesthetic only.

Avoid:
- startup design
- dashboard layouts
- utility-heavy interfaces

## Motion
Framer Motion spring-based transitions only. Added parallax effects for immersive depth in the Hero section.

## Typography
Adopted Cormorant Garamond (font-display) as the primary headline font for a luxury editorial feel.

## Hero Experience
Shifted to a more cinematic centered layout with staggered entrance animations and a persistent parallax background.
Refined the ExperienceAccordion with better content, improved depth, and luxury easing.

## UX
Mobile-first experience prioritized.

## Color Palette

Primary:
- #4A1625
- #5B1E2D
- #D4A373

Avoid:
- neon colors
- bright whites
- harsh black sections
