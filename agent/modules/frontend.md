# Frontend System

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion
- ShadCN UI

## Component Rules

- reusable first
- avoid duplication
- separate feature logic cleanly
- keep animation isolated
- use semantic structure

## Styling Rules

Use only Hessel palette:
- #4A1625
- #5B1E2D
- #7A2E3F
- #D4A373
- #E6BE8A

Typography:
- Playfair Display
- Cormorant Garamond
- Inter

Avoid:
- blue startup aesthetics
- sharp white sections
- neon highlights

## Animation Rules

Animations must:
- be smooth
- be subtle
- use spring motion
- preserve immersion

Avoid:
- bounce-heavy motion
- fast transitions
- playful easing
