# Architecture Principles

## Philosophy

Preserve modularity and cinematic UX.

## Frontend Structure

- feature-first organization
- reusable shared components
- isolated animation logic
- minimal prop drilling

## State Management

- local state first
- global state only when required

## Styling

- Tailwind utility-first
- avoid inline styles
- preserve design consistency

## Component Rules

- one responsibility per component
- avoid giant files
- reuse primitives
- avoid duplicated layouts

## Data Flow

- server/client separation clear
- avoid unnecessary client rendering
- preserve performance
