# Global Rules

## Design Rules

The platform must feel:
- warm
- cinematic
- elegant
- luxurious
- immersive

The platform must NOT feel:
- SaaS-like
- dashboard-heavy
- enterprise-focused
- over-animated
- template-generated

## Engineering Rules

- preserve existing architecture
- prefer extension over replacement
- avoid duplication
- use reusable components
- keep components modular
- maintain responsive behavior

## UI Rules

- mobile-first always
- whitespace matters
- typography drives hierarchy
- avoid visual clutter
- animations must feel heavy and smooth
- avoid hyperactive transitions

## Technical Rules

- Next.js App Router only
- Tailwind for styling
- Framer Motion for interactions
- ShadCN UI for reusable primitives
- Supabase for backend
- PostgreSQL via Supabase

## Forbidden Patterns

- giant sticky navbars
- neon colors
- excessive gradients
- glassmorphism overuse
- tiny unreadable typography
- unnecessary animations
- deeply nested DOM structures
