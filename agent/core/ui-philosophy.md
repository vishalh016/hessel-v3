# UI Philosophy

Hessel is experience-first.

Visual storytelling is more important than information density.

Users should:
- feel guided
- feel immersed
- feel emotionally engaged

The interface should:
- breathe
- use whitespace intentionally
- emphasize imagery
- reduce cognitive load

Avoid:
- clutter
- excessive labels
- dashboard layouts
- enterprise sections
- traditional business site patterns

Motion should feel:
- cinematic
- elegant
- weighty
- premium

Never playful.
