# Navigation System

Navigation must remain minimal.

## Architecture

Use:
- floating trigger
- side drawer navigation
- smooth transitions
- backdrop blur

Avoid:
- top mega navigation
- crowded headers
- enterprise navbars

## Interaction

Desktop:
- hover feedback
- smooth transitions

Mobile:
- touch optimized
- easy thumb access

## Motion

Drawer:
- left slide animation
- spring physics
- cinematic timing
