# Menu Builder

The menu builder is the primary conversion engine.

Must feel:
- guided
- intuitive
- lightweight
- premium

Must NOT feel:
- spreadsheet-like
- operational
- technically overwhelming

## Flow

1. Experience selection
2. Guest count
3. Package selection
4. Dish selection
5. Live pricing
6. WhatsApp quotation

## Rules

- pricing updates dynamically
- mobile-first interactions
- category-based organization
- simple interaction patterns
