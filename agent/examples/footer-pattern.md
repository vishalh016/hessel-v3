# Footer Pattern

## Footer Philosophy

The Hessel footer is not:
- a utility-heavy website footer
- a crowded sitemap
- a corporate information block

The footer should feel:
- cinematic
- warm
- editorial
- emotionally complete
- luxurious

The footer acts as:
- the final emotional layer
- a brand closing experience
- a premium transition point

---

# Visual Tone

The footer should communicate:
- warmth
- hospitality
- elegance
- cinematic atmosphere

Avoid:
- startup footer aesthetics
- enterprise layouts
- excessive utility links
- cluttered information grids

---

# Layout Structure

Preferred structure:

1. Brand identity
2. Short editorial description
3. Curated navigation links
4. Social/contact links
5. Elegant brand signature
6. Large atmospheric typography layer

The layout should:
- breathe
- remain centered
- preserve whitespace
- avoid visual noise

---

# Typography

Use:
- editorial typography
- large cinematic brand text
- warm supporting text

Preferred fonts:
- Playfair Display
- Cormorant Garamond
- Inter

Avoid:
- tiny legal-heavy typography
- overly technical text styling
- dense footer information

---

# Motion Philosophy

Footer motion should feel:
- subtle
- smooth
- elegant

Use:
- soft hover transitions
- restrained opacity animation
- gentle motion refinement

Avoid:
- flashy hover effects
- excessive transforms
- hyperactive interactions

---

# Background Treatment

Use:
- warm gradients
- cinematic overlays
- subtle depth layering
- restrained blur

Avoid:
- technical grid backgrounds
- futuristic effects
- sharp contrast divisions

---

# Navigation Rules

Footer navigation should:
- remain minimal
- support exploration
- preserve simplicity

Avoid:
- giant link collections
- multi-column enterprise layouts
- excessive footer categories

---

# Social Links

Social interactions should feel:
- elegant
- subtle
- premium

Use:
- soft hover transitions
- minimal icon styling
- restrained interaction feedback

Avoid:
- bright social colors
- oversized icons
- aggressive hover states

---

# Brand Signature Layer

Large background typography may be used as:
- atmospheric branding
- cinematic identity reinforcement
- visual depth layer

This layer should:
- remain subtle
- avoid overpowering content
- preserve readability

---

# UX Goals

The footer should leave users with:
- emotional completion
- premium brand memory
- visual warmth
- immersive continuity

The footer should feel like:
- the closing scene of an experience

not:
- the bottom of a webpage.
